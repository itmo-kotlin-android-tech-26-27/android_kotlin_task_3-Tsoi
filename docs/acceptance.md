## Три экрана и один сценарий

- [x] Экран `sections` показывает секции с названиями и локациями, поиск и переход к выбранной секции.
- [x] Экран `section/{sectionId}` показывает показатели одной выбранной секции и её группы.
- [x] Экран `section/{sectionId}/group/{groupId}` показывает сводку одной выбранной группы и действие возврата на главный экран.
- [x] Пройден сценарий: «Бокс» / «Центр · Лиговский проспект, 50» → «Юниоры» → 16 спортсменов, 12 тренировок, 121 / 192 посещения, 63%.
- [x] Предупреждения о низкой посещаемости, пороги и статусы нормы отсутствуют.

## Навигация

- [x] Переходы реализованы через Navigation Compose и `NavHost`.
- [x] Маршруты строковые; `sectionId` и `groupId` объявлены через `navArgument`.
- [x] Данные выбранного объекта не передаются через глобальную переменную или синглтон.
- [x] Системная кнопка «Назад» из сводки возвращает к той же секции и её группам.
- [x] Кнопка «Назад» на экране секции возвращает к списку секций.
- [x] «На главную» открывает исходный список секций и удаляет промежуточные экраны из стека.
- [x] Повторение сценария несколько раз не создаёт цепочку дублирующихся главных экранов.
- [x] Неизвестные `sectionId` и `groupId` проверены тестами ViewModel: состояние `NOT_FOUND`, в UI предусмотрено сообщение и способ возврата.

- [x] Ввести `Бокс` в поиск и повернуть устройство: текст и отфильтрованный результат сохраняются.

- [x] `calculateAttendance` находится в обычном Kotlin-файле без импортов Android и Compose.
- [x] Проверен расчёт группы: `121 / (16 × 12) × 100`, округлённый результат — 63%.
- [x] Проверен расчёт секции: `647 / 816 × 100`, округлённый результат — 79%.

- [x] В плавании открывается группа «Оздоровительная» с нулём тренировок: показатель отсутствует и есть понятное объяснение.
- [x] Отрицательные счётчики и число посещений выше возможного отклоняются в доменных моделях.
- [x] Ошибка чтения или некорректный JSON приводят к сообщению и доступному действию повтора / возврата, приложение не падает.
- [x] Пустой поисковый запрос показывает все секции.
